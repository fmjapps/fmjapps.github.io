Memorize: Lines, Speech, Poems

핸즈프리 암기

연극 대사, 학교에서 외울 시, 연설, 발표… Memorize는 텍스트를 읽어 주고, 내 차례가 되면 듣고, 막히면 무대 프롬프터처럼 알려 줘요. 걷거나 출퇴근하는 중에도 휴대폰에 손대지 않고 연습하세요.

사용 방법

  1. 텍스트 추가

    붙여넣거나 TXT, PDF, Word, 사진에서 가져오세요. 등장인물과 대사는 자동으로 나뉘어요.

  2. 내 역할 선택

    내가 맡을 인물을 고르면 나머지 인물은 서로 다른 목소리로 읽어 줘요.

  3. 리허설 시작

    내 차례가 되면 앱이 들어요. 대사를 말하고 멈추면 다음으로 넘어가요.

  4. 막혔을 때

    프롬프터가 첫 몇 단어를 속삭여 주고, 필요하면 대사 전체를 알려 줘요.

주요 특징

1 / 2

  • 핸즈프리 리허설

    휴대폰을 만질 필요가 없어요. 앱이 읽고, 듣고, 말을 멈추면 다음으로 넘어가요.

  • 어디서든 가져오는 텍스트

    TXT, PDF, Word, 사진. 불분명한 줄은 표시해 주고, 한 번 탭하면 고칠 수 있어요.

  • 시 쌓아 외우기

    1행, 그다음 1~2행, 그다음 1~3행… 시가 한 조각씩 머리에 들어와요.

  • 단계별 가리기

    한 바퀴를 완벽하게 마칠 때마다 더 많은 단어가 사라져요.

주요 특징

2 / 2

  • 어려운 대사만 모아서

    자주 막히는 곳을 기억해 두었다가 그 대사만 따로 연습하게 해 줘요.

  • 발표 연습

    타이머, 목표 시간, 말하기 속도(분당 단어 수). 키워드 힌트 덕분에 한 단어씩 읽는 대신 흐름을 익힐 수 있어요.

  • 내 텍스트는 내 곁에

    텍스트는 휴대폰에 남아요. 리허설 중에는 목소리가 녹음되지 않아요. 휴대폰 안에서 처리되고 어디로도 전송되지 않아요.

  • 10개 언어

    영어, 터키어, 독일어, 프랑스어, 스페인어, 포르투갈어, 러시아어, 이탈리아어, 아랍어, 인도네시아어.

개인정보처리방침

질문과 답변

Memorize는 어디에 쓰면 좋나요?

연극 대사, 시, 학예회, 연설, 발표에 좋아요. 각각에 맞는 연습 방법이 있어요. 등장인물과 함께하는 리허설, 쌓아 외우기, 단계별 가리기, 시간을 재는 발표 연습이에요.

내 목소리가 녹음되나요?

리허설 중에는 녹음되지 않아요. 마이크는 내 차례일 때만 켜지고, 음성은 휴대폰 안에서 실시간으로 처리될 뿐 파일로 저장되거나 어디로 전송되지 않아요. 대사를 내 목소리로 녹음하고 싶다면 “목소리 녹음”에서 직접 시작하면 되고, 그 녹음도 휴대폰에만 남아요.

내 텍스트가 어딘가로 전송되나요?

아니요. 텍스트, 설정, 연습 기록은 휴대폰에만 저장돼요.

광고가 있나요?

아니요. 앱에는 광고가 없고 계정도 필요 없어요.

어떤 파일을 가져올 수 있나요?

TXT, PDF, Word 파일이나 사진을 가져올 수 있어요. 텍스트를 그냥 붙여넣어도 돼요.

iOS 버전이 있나요?

지금은 없어요. 앱은 Android에서만, Google Play를 통해 제공돼요.
