    예시 화면

    포함 내용

    웹사이트에 필요한 모든 것, 준비 완료.

    비즈니스에 맞춰 사이트를 디자인하고, 바로 오픈할 수 있는 상태로 넘겨 드립니다.

    전문적인 디자인

    로고와 브랜드 색상, 하시는 일에 맞춰 만듭니다.

    어떤 화면에서도 깔끔하게

    휴대폰, 태블릿, 컴퓨터에서 모두 읽기 편합니다.

    안전한 연결

    사이트가 HTTPS로 열리고, 브라우저에 자물쇠 표시가 나타납니다.

    문의 양식

    방문자의 메시지가 이메일로 바로 도착합니다.

    한 번 눌러 바로 연락

    전화, WhatsApp, 길 찾기, SNS 링크.

    기본 SEO

    페이지 제목, 설명, 구조화된 데이터, 사이트맵을 Google에 맞게 준비하고 사이트를 Search Console에 등록합니다.

    • 필요하면 여러 언어로
    • 링크를 공유할 때 보이는 미리보기 이미지
    • 빠르게 열리는 깔끔한 페이지
    • 지도에 표시되는 위치

    도메인과 호스팅

    도메인만 준비하세요, 나머지는 저희가 맡습니다.

    호스팅 업체 선택, 서버 설정, 보안 인증서 갱신, 사이트가 멈추지 않도록 관리하는 일까지… 이런 일은 전혀 신경 쓰지 않으셔도 됩니다.

    고객님이 하실 일

    • 본인 명의로 도메인(예: yourbusiness.com)을 등록합니다.
    • 매년 도메인 비용은 도메인 등록 업체에 직접 냅니다.
    • 도메인은 언제나 당신의 것이며, 누구에게도 묶이지 않습니다.

    저희가 할 일

    • 사이트 호스팅을 설정해 드리며, 별도의 호스팅 비용은 들지 않습니다.
    • 도메인을 사이트에 연결하고 HTTPS를 설정합니다.
    • 사이트를 오픈하고 계속 잘 돌아가도록 관리합니다.
    결제 시스템 없음

    사이트에는 장바구니나 온라인 결제가 없습니다. 비즈니스를 소개하는 사이트이며, 고객은 전화, WhatsApp, 문의 양식으로 연락합니다.

    진행 방법

    세 단계면 오픈.

    1. 비즈니스를 소개해 주세요

      하시는 일, 로고, 사진, 연락처를 보내 주세요. 가지고 계신 것만으로도 시작할 수 있습니다.

    2. 디자인은 함께 다듬습니다

      사이트를 만들어 보여 드리고, 원하시는 대로 수정한 뒤 확인을 받습니다.

    3. 도메인 등록, 그리고 오픈

      본인 명의로 도메인을 등록하시면, 저희가 연결하고 HTTPS를 설정해 사이트를 오픈합니다.

    누구를 위한 서비스인가요?

    온라인에서 자신을 제대로 보여 주고 싶은 모든 분께.

    • 카페와 레스토랑
    • 병원과 의료 기관
    • 미용실과 뷰티 숍
    • 부동산 중개
    • 변호사와 컨설턴트
    • 기술자와 수리 서비스
    • 개인 사이트와 포트폴리오

    자주 묻는 질문

    궁금하신 점

    도메인은 어디서 등록하나요?

    어느 도메인 등록 업체에서든 본인 명의로 등록하시면 됩니다. 어디를 고를지 모르겠다면 함께 살펴봐 드릴게요.

    호스팅 비용을 따로 내야 하나요?

    아니요. 사이트 호스팅은 저희가 설정하고 관리하며, 준비하실 것은 도메인뿐입니다.

    사이트에서 온라인 판매를 할 수 있나요?

    아니요, 결제 시스템은 구축하지 않습니다. 사이트는 비즈니스를 소개하는 용도이며, 고객은 전화, WhatsApp, 문의 양식으로 연락합니다.

    글과 사진은 누가 준비하나요?

    정보와 사진을 보내 주시면, 사이트에서 읽기 좋은 글로 다듬어 확인용으로 보내 드립니다.

    나중에 수정할 수 있나요?

    네. 바꾸고 싶은 부분을 알려 주시면 범위를 함께 정하고 사이트를 업데이트해 드립니다.

    SEO도 해 주시나요?

    모든 사이트에 기본 SEO를 적용합니다. 페이지 제목과 설명, 깔끔한 제목 구조, 구조화된 데이터, 사이트맵, 빠른 로딩, Search Console 등록까지요. 다만 Google에서 특정 순위를 보장하지는 않습니다. 순위는 시간이 지나면서 쌓이며, 콘텐츠와 경쟁 상황에 따라 달라집니다.

    비용은 얼마인가요?

    가격은 문의해 주세요. 필요하신 내용에 맞는 견적을 보내 드리겠습니다.
